Microsoft lanza Windows NT 4.0 (1996)

El 28 de agosto de 1996, Microsoft lanzó oficialmente Windows NT 4.0, una versión que consolidó la estabilidad del núcleo NT en el entorno empresarial. Este sistema introdujo la interfaz de usuario de Windows 95 en la arquitectura robusta de NT, convirtiéndose en un estándar para servidores y estaciones de trabajo de alto rendimiento durante años.
