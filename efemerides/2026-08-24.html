Windows 95 sale a la venta oficialmente (1995)

El 24 de agosto de 1995, Microsoft lanzó al mercado Windows 95, un sistema que marcó un antes y un después en la informática personal. Introdujo por primera vez elementos icónicos como el botón de Inicio, la barra de tareas y el soporte para nombres de archivo largos, cambiando para siempre la interfaz de usuario de escritorio.
