Lanzamiento de la versión 1.0 de Windows (1985)

📅 Este hecho ocurrió este mismo mes, no exactamente el día de hoy.

El 20 de noviembre de 1985, Microsoft lanzó oficialmente la primera versión de Windows, marcando un hito en la informática al introducir una interfaz gráfica de usuario para MS-DOS. Aunque inicialmente fue una extensión del sistema operativo existente, este lanzamiento sentó las bases para la dominancia de Windows en el mercado de las computadoras personales durante las décadas siguientes.
