Microsoft lanza Windows NT 4.0 Service Pack 3 (1997)

El 29 de agosto de 1997, Microsoft lanzó el Service Pack 3 para Windows NT 4.0, una actualización crítica que mejoró significativamente la estabilidad y seguridad del sistema operativo. Este paquete fue fundamental para consolidar a NT 4.0 como la plataforma empresarial dominante de finales de los noventa, introduciendo mejoras clave en la gestión de red y el soporte de aplicaciones.
