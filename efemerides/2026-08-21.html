Microsoft lanza Windows 95 (1995)

📅 Este hecho ocurrió este mismo mes, no exactamente el día de hoy.

El 24 de agosto de 1995, Microsoft lanzó oficialmente Windows 95, un sistema operativo que marcó un antes y un después en la informática personal. Introdujo elementos icónicos como el botón de Inicio, la barra de tareas y el soporte para nombres de archivo largos, consolidando la interfaz gráfica como estándar para millones de usuarios.
