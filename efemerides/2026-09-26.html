Microsoft lanza Windows NT 4.0 Option Pack (1997)

El 26 de septiembre de 1997, Microsoft lanzó el Option Pack para Windows NT 4.0, un paquete de software fundamental que introdujo Internet Information Server (IIS) 4.0 y otras herramientas de servidor críticas. Este lanzamiento fue clave para consolidar a Windows NT como una plataforma robusta para el despliegue de aplicaciones web empresariales en la era de la expansión de Internet.
