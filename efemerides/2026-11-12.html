Microsoft lanza la versión 1.0 de Windows (1985)

📅 Este hecho ocurrió este mismo mes, no exactamente el día de hoy.

El 20 de noviembre de 1985, Microsoft lanzó oficialmente Windows 1.0, su primera interfaz gráfica de usuario para el sistema operativo MS-DOS. Este hito marcó el inicio de una nueva era en la computación personal, permitiendo a los usuarios interactuar con el ordenador mediante ventanas y un ratón en lugar de comandos de texto.
